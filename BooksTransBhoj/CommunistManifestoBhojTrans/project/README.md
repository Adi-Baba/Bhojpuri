# Communist Manifesto Bhojpuri Translation

## Purpose

Translate *The Communist Manifesto* into everyday Bhojpuri using Devanagari script. Output should feel natural, theth and bolchal-style, not formal or Sanskrit-heavy.

## Source Edition

This Bhojpuri translation is based on the following English edition:

- **Title:** *The Communist Manifesto (Illustrated)*
- **Authors:** Karl Marx & Friedrich Engels
- **Year:** 2014
- **ASIN:** B00MJJ7YZE
- **Source:** Anna's Archive (EPUB)

## Structure

- `source/` — Bhojpuri translation drafts (in `translations/` subdirectory).
- `fonts/` — local font files used for Devanagari rendering.
- `tex/` — LaTeX or document files for translation output and builds.

## Fonts used

The translation uses Devanagari fonts from the user's local install, now bundled in `fonts/`:
- **TiroDevanagariSanskrit** (Regular, Italic) — main body font
- **Kurale** (Regular) — available as `\kurale` for display use

## Workflow

1. Translate section-by-section in Bhojpuri Devanagari.
2. Place translation drafts in `source/translations/`.
3. Build or proof output from `tex/`.
4. Iterate for tone and colloquial vocabulary.
