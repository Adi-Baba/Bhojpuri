# Communist Manifesto Bhojpuri Translation

## Purpose

Translate *The Communist Manifesto* into everyday Bhojpuri using Devanagari script. Output should feel natural, theth and bolchal-style, not formal or Sanskrit-heavy.

## Structure

- `source/` — extracted original EPUB text and translation drafts.
- `fonts/` — local font files used for Devanagari rendering.
- `tex/` — LaTeX or document files for translation output and builds.

## Fonts used

The translation will use Devanagari fonts from the user's local install. If the fonts are not in this folder yet, copy them here from:
- `/home/aditya/Documents/MyBiraha/Font/Kurale/Kurale-Regular.ttf`
- `/home/aditya/Documents/MyBiraha/Font/Tiro_Devanagari_Sanskrit/TiroDevanagariSanskrit-Regular.ttf`
- `/home/aditya/Documents/MyBiraha/Font/Tiro_Devanagari_Sanskrit/TiroDevanagariSanskrit-Italic.ttf`

## Workflow

1. Extract EPUB into `source/`.
2. Translate section-by-section in Bhojpuri Devanagari.
3. Build or proof output from `tex/`.
4. Iterate for tone and colloquial vocabulary.
